1. Что это и как устроено

Система помогает находить бизнесы, хранить их контакты и аккуратно писать им холодные письма — вручную, по одному, без массовых рассылок и без спама.

Поток данных:

  1. Сбор (Collector) — собирает сайты бизнесов из источников (OSM-карты, веб-поиск).
  2. Склад (Warehouse) — извлечённые контакты компаний. Сейчас ~77 000 контактов, ~75 000 проверенных. Это НЕ адресаты рассылки, это база.
  3. Выбор — оператор выбирает из склада небольшую группу подходящих лидов.
  4. Очередь (Manual Outreach Queue) — выбранные лиды с черновиками писем, статус «на проверке».
  5. Отправка — оператор отправляет по одному: копированием в веб-почту или по SMTP через свой ящик.
  6. Ответы (Replies) — импорт ответов по IMAP, классификация, подавление отказов.

2. Словарь терминов

Лид / контактEmail компании из склада. Пока не адресат — просто запись.

Mailbox (Ящик)Ваш почтовый ящик-отправитель (например Zoho), через который шлёте.

3. Роли: клиент и админ

Клиент / оператор — повседневная работа: ящики, шаблоны, выбор лидов, отправка, ответы. Разделы: Go Live, Mailboxes, Sender Studio, Warehouse, Manual Outreach.

Админ (super-admin) — управление системой и безопасностью: Safety (паузы/риски), управление тенантами, Collector (сбор лидов), домены/прогрев, темы. Эти пункты видны только админу.

4. Быстрый старт за 6 шагов

Открой Go Live — там виден прогресс (оценка 0–100) и ровно следующая кнопка.
Шаг 1. Ящик. Mailboxes → добавить ящик → 🔑 Данные входа → ввести email и app-пароль → Save → Тест SMTP / IMAP → Активировать.
Шаг 2. Шаблон. Sender Studio → открыть Clients.Help первое касание → проверить отписку и адрес → Одобрить.
Шаг 3. Выбор лидов. Go Live → «Показать 20 существующих лидов» (тест, ничего не создаётся).
Шаг 4. Очередь. Go Live → «Создать безопасную очередь» (до 20 черновиков «на проверке»).
Шаг 5. Отправка дня 1. Manual Outreach → Queue → одобрить и отправить 5 писем по одному.
Шаг 6. Ответы. Manual Outreach → Replies → импорт → отказы в подавление.

5. Go Live — центр запуска

Главный экран для запуска. Показывает:

  • Оценка готовности 0–100 и статус (Не готово → Нужна настройка → Готов к копированию → Готов к SMTP по одному → Работает безопасно).
  • Сегодня — активные ящики, безопасный лимит дня 1, отправлено/осталось, очередь, ответы.
  • Чек-лист из 7 шагов с метками Готово / Нужно действие / Заблокировано и ссылкой «как починить».
  • Выбор существующих лидов — источник (склад / вручную вставить email), кнопки: Показать 20 (тест), План дня 1, Создать очередь.

Важно: Go Live НЕ ищет новых лидов. Берёт только из уже собранного склада. Ничего не отправляет сам.

6. Mailboxes — почтовые ящики

Три вкладки: Обзор парка (сводка), Ящики, Профили провайдеров.

Как подключить ящик Zoho полностью из интерфейса

  1. Вкладка Профили провайдеров → «Создать профиль Zoho EU» (хост smtp.zoho.eu:587 / imap.zoho.eu:993).
  2. Вкладка Ящики → «Добавить ящик»: email, выбрать профиль, назначение cold_outreach, галка Inbound (IMAP) если нужны ответы.
  3. В строке ящика нажать 🔑 Данные входа → ввести SMTP логин (это email) и SMTP пароль. Галка «IMAP как у SMTP» если логин/пароль те же → Сохранить.
  4. Нажать SMTP — должно показать «SMTP-тест ПРОЙДЕН». Потом IMAP — «IMAP-тест ПРОЙДЕН».
  5. Нажать Активировать. Если тест не пройден — активация заблокируется и покажет причину.
Данные вводятся прямо здесь и шифруются в базе — править файлы на сервере НЕ нужно. Пароль обратно никогда не показывается (только на запись). Значок 🔑 в колонке «Tests» = данные сохранены.
Zoho: нужен app-specific пароль (Zoho → Settings → Security → App Passwords; требуется 2FA), и включённый IMAP (Settings → Mail Accounts → IMAP Access = ON). Бесплатный тариф Zoho часто не даёт SMTP/IMAP — нужен платный.

Результаты теперь не мигают

Сообщение о результате (SMTP/IMAP/Активация) висит вверху, пока не нажмёшь «Закрыть ✕». Тест показывает правду: «ПРОЙДЕН» только при реальном успехе.

7. Sender Studio — шаблоны писем

Редактор и одобрение шаблонов. Поля для подстановки показаны как <<< REPLACE: ... >>>.

  1. Открыть шаблон Clients.Help первого касания (напр. ch_first_touch_no_ps).
  2. Проверить превью (desktop/mobile/dark), наличие ссылки отписки и почтового адреса (требование закона).
  3. Нажать Одобрить. Если опасно/нет отписки — одобрение заблокируется и покажет проблемы.

Без одобренного шаблона очередь создать нельзя — это защита.

8. Warehouse — база лидов

Вкладки: Поиск лидов, Компании, Контакты, Очередь на разбор, Аналитика. Здесь смотрят и фильтруют уже собранные контакты, строят когорты (Cohort Builder), выгружают в CSV (с лимитом, без «выгрузить всё»). Отсюда же берёт лидов Go Live.

Правила «годного» лида: проверен, не в подавлении (глобально и по тенанту), не отписан/не отскок/не жалоба, есть email, желательно есть сайт/компания.

9. Manual Outreach — рассылка по одному

Вкладки: Сегодня, Setup, Providers, Cohort, Queue, Replies, Follow-ups, Warmup, Templates.

  • Queue — очередь. Каждый элемент: проверить черновик, одобрить, затем «Копировать» (вставить в Zoho) или «Отправить» (SMTP), потом «Отметить отправленным».
  • Replies — «Импортировать ответы» (нужен IMAP). Ответы классифицируются: интересно / не интересно / отписка / похоже на отскок. Отказ → «Подавить» навсегда.
  • Follow-ups — ручные задачи-напоминания (1-2 касания). Если пришёл ответ — фоллоу-ап автоматически отменяется.
  • Warmup — рекомендованный объём по дням (день1=5, дни2-3=10, дни4-7=15, дальше 20). Только рекомендация.

10. Ежедневный режим работы

  1. Открыть Go Live или Manual Outreach → Сегодня. Посмотреть «следующее действие».
  2. Ответить интересующимся (Replies).
  3. Отправить просроченные фоллоу-апы.
  4. Отправить дневную норму новых писем (день1=5), по одному.
  5. Импортировать новые ответы, отказы → в подавление.
  6. Дошёл до лимита — стоп до завтра. Есть отскоки/жалобы — пауза, не наращивать.
Не наращивай объём, пока не получишь первые реальные ответы. Новый ящик на большом объёме = спам/блок.

11. Админский функционал

РазделЧто делает
SafetyКонтроль безопасности: события риска, постановка тенанта на паузу/снятие, лимиты.
CollectorСбор новых лидов: кампании сбора, источники (OSM-карты, веб-поиск), предпросмотр/импорт, статус агента сбора. Это пополняет склад.
DomainsДомены отправки: DNS-проверка (SPF/DKIM/DMARC), онбординг, прогрев домена.
Send ControlИнфраструктура отправки: провайдеры, ящики, вебхуки, kill-switch (общий стоп).
Admin / ThemeУправление тенантами и оформлением (только super-admin).
CampaignsМассовые кампании (классический движок). Заблокированы пока системный SMTP не настроен — защита от случайной массовой отправки.

Доступ к админ-разделам — у пользователя с признаком super-admin. Переключение тенанта — параметром ?tenantId= в адресе.

13. Безопасность и лимиты — что система НЕ делает

  • Нет кнопки «отправить всем». Нет автоматических отправок.
  • Нет одобренного шаблона → нельзя создать очередь.
  • Нет активного ящика и не выбран режим копирования → нельзя создать очередь.
  • Подавленные/отписанные/невалидные/отскоки исключаются всегда.
  • Дошёл до лимита ящика → нельзя слать. Пришёл ответ → фоллоу-ап отменяется.
  • Секреты хранятся шифрованно, обратно не показываются, в логи не пишутся.
  • Массовые кампании заблокированы, пока не настроен боевой системный SMTP.

14. Частые проблемы

SMTP-тест «ПРОВАЛЕН: не настроено» — не введён пароль. Нажми 🔑 Данные входа, введи app-пароль, сохрани.

SMTP/IMAP тест с ошибкой авторизации — у Zoho нужен app-specific пароль (не пароль входа) и включённый IMAP; на бесплатном тарифе доступа может не быть.

«Активировать» не срабатывает — сначала должен пройти SMTP-тест (зелёный). Причина показывается в сообщении.

Результаты «мигают» — исправлено: сообщение висит до закрытия ✕.

«Нет одобренного шаблона» — Sender Studio → одобрить шаблон.

Очередь пустая — Go Live → «Создать безопасную очередь».

Интерфейс на английском — переключатель языка внизу меню (ru/uk/en).
