# Полное руководство по системе emails.cheap (клиент + админ)

> Версия для чтения и для передачи в ChatGPT. HTML-версия живёт на
> `https://emails.cheap/guide-ru.html` (короткая — `/start-ru.html`).

## 1. Что это
Платформа холодной B2B email-рассылки на собственных собранных лидах. Всё вручную,
по одному, без массовых рассылок и спама.

**Поток данных:** Collector (сбор сайтов) → Warehouse (склад ~77k контактов, ~75k
проверенных) → оператор выбирает ≤20 лидов → очередь Manual Outreach (статус
`pending_review`) → отправка по одному (copy-mode или SMTP через свой ящик) →
импорт ответов по IMAP → подавление отказов.

## 2. Словарь
- **Лид/контакт** — email компании из склада (пока не адресат).
- **Warehouse** — база собранных контактов.
- **Mailbox** — ваш ящик-отправитель (Zoho и т.п.).
- **Provider profile** — настройки сервера почты (SMTP/IMAP хост+порт), общие для ящиков.
- **Template** — шаблон письма; должен быть одобрен перед отправкой.
- **Suppression** — чёрный список (отписки/жалобы/отказы).
- **Warmup** — постепенное наращивание объёма нового ящика.
- **Copy-mode** — отправка без SMTP (скопировать → вставить в веб-почту).

## 3. Роли
- **Клиент/оператор:** Go Live, Mailboxes, Sender Studio, Warehouse, Manual Outreach.
- **Админ (super-admin):** Safety, Collector, Domains, Send Control, Admin/Theme,
  управление тенантами (`?tenantId=` в адресе).

## 4. Быстрый старт (6 шагов) — начинать с `/go-live`
1. **Ящик:** Mailboxes → добавить → 🔑 Данные входа → email + app-пароль → Save →
   Тест SMTP/IMAP → Активировать.
2. **Шаблон:** Sender Studio → открыть Clients.Help первое касание → проверить
   отписку+адрес → Одобрить.
3. **Лиды:** Go Live → «Показать 20 существующих лидов» (тест, ничего не создаётся).
4. **Очередь:** Go Live → «Создать безопасную очередь» (до 20 черновиков pending_review).
5. **День 1:** Manual Outreach → Queue → одобрить и отправить **5** по одному.
6. **Ответы:** Manual Outreach → Replies → импорт → отказы в подавление.

## 5. Go Live — центр запуска
Оценка готовности 0–100 + статус (Не готово → Нужна настройка → Готов к копированию →
Готов к SMTP по одному → Работает безопасно → Пауза из-за риска). Чек-лист 7 шагов с
метками Готово/Нужно действие/Заблокировано и ссылкой «как починить». Панель выбора
существующих лидов (источник: склад / вставить email вручную), кнопки Показать 20 /
План дня 1 / Создать очередь. **Не ищет новых лидов, ничего не шлёт сам.**

## 6. Mailboxes — подключение ящика (полностью из UI)
Вкладки: Обзор парка / Ящики / Профили провайдеров.
1. Профили → «Создать профиль Zoho EU» (smtp.zoho.eu:587 / imap.zoho.eu:993).
2. Ящики → «Добавить ящик»: email, профиль, назначение cold_outreach, галка Inbound(IMAP).
3. В строке → **🔑 Данные входа** → SMTP логин (email) + SMTP пароль, галка «IMAP как у
   SMTP» → Сохранить. **Данные шифруются в БД, .env править не нужно.** Пароль обратно
   не показывается. Значок 🔑 = сохранено.
4. **SMTP** → «ПРОЙДЕН», **IMAP** → «ПРОЙДЕН».
5. **Активировать** (заблокировано пока SMTP-тест не зелёный — причина в сообщении).

**Zoho:** нужен app-specific пароль (Settings → Security → App Passwords, нужна 2FA) +
включённый IMAP (Settings → Mail Accounts → IMAP Access = ON). Бесплатный тариф часто
без SMTP/IMAP. Сообщения о результате висят до закрытия ✕ (не мигают); тест показывает
правду — «ПРОЙДЕН» только при реальном успехе.

## 7. Sender Studio — шаблоны
Поля подстановки = `<<< REPLACE: ... >>>`. Открыть шаблон → проверить превью
(desktop/mobile/dark), наличие ссылки отписки и почтового адреса → Одобрить.
Без одобренного шаблона очередь не создать.

## 8. Warehouse — база лидов
Поиск / Компании / Контакты / Очередь на разбор / Аналитика. Фильтры, когорты
(Cohort Builder), выгрузка CSV с лимитом (без «выгрузить всё»). Годный лид: проверен,
не в подавлении (глобал+тенант), не отписан/отскок/жалоба, есть email, желательно сайт.

## 9. Manual Outreach
Вкладки: Сегодня / Setup / Providers / Cohort / Queue / Replies / Follow-ups / Warmup /
Templates.
- **Queue** — проверить черновик → одобрить → Копировать (в Zoho) или Отправить (SMTP) →
  Отметить отправленным.
- **Replies** — Импортировать ответы (IMAP). Классы: интересно / не интересно / отписка /
  отскок. Отказ → Подавить навсегда.
- **Follow-ups** — ручные задачи (1-2 касания). Ответ → фоллоу-ап отменяется.
- **Warmup** — день1=5, дни2-3=10, дни4-7=15, далее 20 (рекомендация).

## 10. Ежедневный режим
Сегодня → следующее действие → ответить интересующимся → просроченные фоллоу-апы →
дневная норма (день1=5) по одному → импорт ответов, отказы в подавление → лимит/жалобы →
стоп. Не наращивать объём до первых реальных ответов.

## 11. Админский функционал
- **Safety** — события риска, пауза/снятие тенанта, лимиты.
- **Collector** — сбор лидов (кампании, источники OSM/веб-поиск, предпросмотр/импорт,
  статус агента); пополняет склад.
- **Domains** — DNS (SPF/DKIM/DMARC), онбординг, прогрев домена.
- **Send Control** — провайдеры, ящики, вебхуки, kill-switch (общий стоп).
- **Campaigns** — массовый движок; заблокирован пока системный SMTP не настроен.
- **Admin / Theme** — тенанты и оформление (super-admin).

## 12. Безопасность — чего система НЕ делает
Нет «отправить всем», нет автосенда. Нет одобренного шаблона → нет очереди. Нет
активного ящика и не выбран copy-mode → нет очереди. Подавленные/отписанные/невалидные/
отскоки исключаются всегда. Лимит ящика достигнут → нельзя слать. Ответ → фоллоу-ап
отменяется. Секреты шифрованы, не показываются, не логируются. Массовые кампании
заблокированы без боевого SMTP.

## 13. Частые проблемы
- «SMTP ПРОВАЛЕН: не настроено» → нет пароля, нажми 🔑 и введи app-пароль.
- Ошибка авторизации SMTP/IMAP → у Zoho нужен app-пароль и включённый IMAP; бесплатный
  тариф может не давать доступ.
- «Активировать» не срабатывает → сначала зелёный SMTP-тест.
- «Нет одобренного шаблона» → Sender Studio → одобрить.
- Очередь пустая → Go Live → создать очередь.
- Английский интерфейс → переключатель языка внизу меню.
